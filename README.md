# PT. Digvijaya Nusantara Kalandra — Website

Website company profile statis, siap untuk GitHub Pages.

## Upload ke GitHub Pages

1. Buat repository publik bernama `digvijayanusantarakalandra.github.io`.
2. Upload `index.html`, `style.css`, folder `assets`, dan `README.md`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Website akan tersedia di `https://digvijayanusantarakalandra.github.io/` setelah proses deployment selesai.

Tidak membutuhkan hosting berbayar untuk website statis ini.
